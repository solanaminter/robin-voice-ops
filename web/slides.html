◉ Robin Voice Ops

The voice dispatcher for home-services businesses. It doesn't just talk — it books, checks, logs, and escalates, with a human approval gate on everything irreversible.

Solana Minter · Purple Castle Ventures · solo entry · live demo

The problem

Small contractors drown in phone calls

  • Up to ~62% of calls to home-services SMBs go unanswered during job hours (industry call-tracking reports)
  • Every missed call is $200–$500 of lost revenue walking to a competitor
  • After-hours dispatchers cost $3k+/month — unaffordable for 2–10 person shops
  • Existing "AI receptionists" are prompt wrappers: they take messages, they can't do anything

The solution

A dispatcher with hands, not just a mouth

  • 📞 Answers every call, 24/7, on web and real phone lines (Twilio bridge)
  • 🛠 Real tools, real side effects: books appointments, checks job status, files service requests, answers from a knowledge base
  • 🛡 Human approval gates — nothing irreversible happens on voice alone; every action lands in a hash-chained audit log
  • 🧠 Cross-session caller memory — repeat callers are recognized and greeted by name

How it works — the call

"My water heater is leaking…"

  • Caller speaks → check_availability finds a real slot in the bookings DB
  • book_appointment fires in hold mode — the agent goes quiet, the request pends in the dispatcher dashboard
  • Human approves → tool.result delivered → agent announces the confirmation
  • Rejected? The agent offers the next slots. No hallucinated bookings, ever.

Application of technology — depth, not wrapping

  • session.update with progressive tool reveal — the booking tool doesn't exist until real slots are found (anti-fabrication by construction)
  • Hold-mode execution for gated actions + reply.create status updates; interactive mode for lookups
  • keyterms_prompt biased per trade, transcription_prompt for entities, voice_focus near-field
  • Temp-token auth (GET /v1/token) — the API key never reaches the browser
  • session.resume reconnection, barge-in flush, word-level agent captions
  • Parameter hints (enum/pattern/examples/format) so spoken phone numbers validate before tools run
